# 足し算・引き算のセルは、全軸を持つ側のセルからだけ作る

2026-11-02

## 決めたこと

`+` と `-` の結果のセルは、結果の全軸を持つ側のセル(両側とも全軸なら和集合)にだけ作る。軸の少ない側は、既にあるセルに足し引きするだけで、新しいセルを作らない。軸の少ない側に値がないセルでは 0 として扱う。どちらの側も全軸を持たないときは、両側にある組だけがセルになる。

## 理由

軸の少ない側を全メンバーに広げると、疎なメジャーが密になる。1億セル(充填 0.17%)の売上に `'単価'[商品, 期間]` を足すだけで 6×10^10 セルになり、作れない。Essbase も、数式が新しいブロックを作るのは明示したときだけにしている。

## 選ばなかった案

- **設計書のとおり、空を 0 として全組み合わせに広げる**: 上の理由で、PoC の規模では実現できない。

## 影響

- `'売上' + 1` は売上にあるセルにだけ 1 を足す。
- 設計書の「空の扱い」と例の式は、まだこの決定に合わせていない。
- 全軸を持つ側がない式(`'単価'[商品, 期間] + '人員'[部門, 期間]` など)の扱いは、Fable の推奨に従って決めた。利用者の確認はまだ。
